# ColorfulWallpapers

[ColorfulWallpapers](https://colorfulwallpapers.com/) — A library of original, free HD phone wallpapers sorted by color for iPhone and Android.

## Official website

**[ColorfulWallpapers](https://colorfulwallpapers.com/)**

## Mini tool (in this repo)

Open [`tools/index.html`](tools/index.html) for a tiny browser helper (Color swatch preview). It runs locally in your browser and links out to the live site.
